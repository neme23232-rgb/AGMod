## Что это

**AGMod** — комплексная модификация для **Google Antigravity 2.0**, которая добавляет полноценную систему визуальных тем оформления, интерактивную студию кастомных цветов, поддержку системных шрифтов Windows и полную локализацию всей рабочей среды.

Модификация интегрируется прямо в интерфейс Antigravity в виде нативной вкладки в диалоговом окне Настроек. Всё работает локально на компьютере, не требует административных прав и не передаёт данные в сеть.

## Возможности

- 🎨 **14 готовых дизайнерских тем** — от глубоких тёмных (*Catppuccin Mocha, Cyberpunk Neon, OLED Pure Black, Dracula, Tokyo Night, Nord*) до чистых светлых (*GitHub Light, Catppuccin Latte*) с автоматической подстройкой контраста текста.
- 🛠️ **Студия кастомных цветов** — настраивайте акцент, фон, сайдбар и карточки с интерактивным окном предпросмотра синтаксиса `preview.ts`.
- 🔤 **Шрифты с вашего ПК** — автоматическое обнаружение всех установленных в Windows шрифтов (`queryLocalFonts`) и прямая загрузка локальных файлов (`.woff2`, `.ttf`, `.otf`).
- 🌐 **100% локализация** — перевод всей рабочей зоны (настройки, чат, диффы, терминал, меню и команды агента). Доступно 7 языков: русский (1700+ фраз), украинский (1700+ фраз), английский, немецкий, французский, испанский и китайский.
- 🗜️ **Компактный режим (Deep High-Density)** — сжатие боковой панели до 220px и оптимизация отступов для максимального обзора кода.
- 💾 **Тройное сохранение (Triple Persistence)** — настройки синхронно пишутся на диск (`agmod_settings.json`), в хранилище приложения и в `localStorage`. Ничего не сбрасывается при перезапуске.

## Быстрый старт

1. Закройте **Google Antigravity**, если он запущен.
2. Скачайте репозиторий или распакуйте архив.
3. Запустите файл **`install.bat`** (или выполните команду `node install.js`).
4. Запустите Google Antigravity, откройте **Настройки** (значок шестерёнки) и выберите вкладку **AGMod**.

> [!TIP]
> Установщик автоматически создаёт резервную копию оригинального файла (`app.asar.backup`), поэтому вы всегда можете вернуть исходный вид в один клик.

## Удаление

Чтобы полностью удалить мод и вернуть оригинальный Antigravity:
1. Запустите файл **`uninstall.bat`** (или `node uninstall.js`).
2. Запустите Antigravity — приложение вернётся в исходное состояние.
